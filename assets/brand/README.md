# RecallSpring favicon pack

Source: the Recall Loop concept from the chosen logo presentation.

Files:
- `favicon.svg` – an approximate vector reconstruction of the silhouette.
- `favicon.ico` – combines 16, 24, 32, 48, 64, 128 and 256 px.
- `favicon-NxN.png` – transparent PNG icons.
- `apple-touch-icon.png` – 180×180, dark green background, white mark.
- `pwa-192x192.png`, `pwa-512x512.png` – for a PWA.
- `recallspring-symbol-1024.png` – transparent high-resolution source.

Use in HTML:
```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
```

Note: the SVG was vectorised automatically from the concept image; it is not an original hand-drawn vector file.
