The first pre-release of RecallSpring: a self-hosted study companion that keeps your material, notes, grades and
review schedule on your own computer, while you study with your own assistant (Claude, Codex, Antigravity).

This release is for trying the **one-command install with Docker** (Linux, macOS, Windows with Docker Desktop).
Expect rough edges, and keep your own backups.

### Install

With Docker running. Linux and macOS (or Git Bash on Windows):

```sh
curl -fsSL https://github.com/kek-tilen/RecallSpring/releases/download/v0.1.0-beta.1/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://github.com/kek-tilen/RecallSpring/releases/download/v0.1.0-beta.1/install.ps1 | iex
```

It checks Docker, disk space and ports, says what it will do and asks first, checks every file below against
`SHA256SUMS`, and prints a one-time link for your account. Everything listens on 127.0.0.1 only. The full guide:
[docs/install-docker.md](https://github.com/kek-tilen/RecallSpring/blob/main/docs/install-docker.md).

A pre-release is not "latest": update it with `recallspring update --beta`.

### What is in it

- Images for amd64 and arm64: `ghcr.io/kek-tilen/recallspring:v0.1.0-beta.1`, and `-full` with LibreOffice, which
  shows Word, PowerPoint and OpenDocument pages as they look (`--full`). Both are pinned by digest in `images.env`,
  with build provenance:
  `gh attestation verify oci://ghcr.io/kek-tilen/recallspring:v0.1.0-beta.1 --owner kek-tilen`.
- `compose.yml`, the `recallspring` command (`recallspring.ps1` on Windows), `install.sh`, `install.ps1`, `SHA256SUMS`.

### Not tested yet

Docker install, ChatGPT sign-in from inside Docker, iCloud Drive as the sync folder, and `update` from one release to
the next. Please open an issue with what you find.
