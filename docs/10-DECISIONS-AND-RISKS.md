## Working assumptions (do not mistake for owner approval)

- Single-user app first; app login uses local credentials (Argon2id + optional TOTP) independent of any AI provider, no public self-signup. The first-run page (Phase 3) is not self-signup: it creates only the first account, from the same computer, and is off in production.
- Phase 3 defaults: the time zone defaults to the browser's (UTC on the server); "Decide later" is allowed and changes only wording; the chosen assistant never limits which assistants work.
- ChatGPT's tools come in two sets so it never has more than 20 at once (OpenAI's advice for accurate tool use): a planning conversation (no course) reads and sets up courses, filing, concepts, study targets and exam profiles but cannot ask or grade; a study conversation has the study tools plus setting up its own course only (`other_course` otherwise). A call from the other set is refused with where it is available. Material is added in Library, never by ChatGPT.
- Deployment subdomain not chosen. Do not buy/register a domain or issue certificates automatically. Remote Claude connector (web/mobile) waits for domain + HTTPS.
- Supported material: PDF (scanned pages viewable by Claude as images), Word/PowerPoint/Excel, OpenDocument, Markdown/plain text, CSV/TSV, subtitles, notebooks, LaTeX, source code and photos; OCR and audio are later features.
- Upload limits (owner can change them with `RS_MAX_UPLOAD_BYTES`, `RS_MAX_TEXT_UPLOAD_BYTES`, `RS_MAX_IMAGE_UPLOAD_BYTES`, `RS_MAX_LIBRARY_BYTES`, `RS_MIN_FREE_DISK_BYTES`): 100 MiB per document (PDF, Office, OpenDocument, notebook), 10 MiB per text file, 20 MiB per photo, 2 GiB per library; uploads pause when the storage disk would drop below 2 GiB free. Reasoning: a lecture PDF is 1-20 MB and a deck with photos 30-80 MB, while the text of even a 600-page book is a few MB, so above ~100 MB a file grows by pictures, scans or video, not by text Claude can use; up to ~200 MiB still works (extraction caps: 600 pages, 256 MiB unpacked Office data, 3 M characters, 2 GiB memory, 120 s), beyond that split or compress the file.
- "University first until its requirements are met" is read as: interests get today's left-over minutes only while every exam's capacity check is `ok`; a focus lasts at most 60 days and its days are not counted for other exams (conservative warnings); a plan for one course or interest applies no priority rules (ADR-007).
- Local backups live next to the uploads by default (same disk) and are not encrypted; Settings says so and `RS_BACKUP_DIR` moves them. Backups cover the whole instance, so any signed-in account (one learner per install) sees their status and can start one. Backups run from the worker, not an OS scheduled task, so none are made while RecallSpring is stopped (Today warns after two days).
- Readiness states are a plain reading of recorded evidence, not a grade prediction: "weak" means the last effective grade was 0-2, a lapse or band `emerging`; "solid" means band `reliable`. A timed simulation is suggested only when the exam is at most 10 days away, at least half of the scope is studied and none was submitted in the last 7 days. Weekly study time counts only sessions closed with a summary (capped at 4 h each); the page says so.
- Device sync = the browser's offline draft outbox plus sync to the RecallSpring server; no automatic filesystem mirroring.
- Backend FastAPI/Python, React/TypeScript, PostgreSQL and Docker Compose based on resource and developer productivity; can change only with documented rationale (ADR-001).
- Default spaced intervals and mastery bands are an explainable heuristic, not a scientific certification (ADR-003).
- ChatGPT's RecallSpring tools in Chat run without a per-call confirmation: the learner turned the `RecallSpring` switch on and pressed Send, every tool only reads or appends through the connector's server-side checks, each step is listed under the message and audited, and nothing can be deleted or changed in settings. Answers and summaries are never taken from chat text, only from RecallSpring's forms. Limits: 6 responses and 12 calls per message.
- `include: ["reasoning.encrypted_content"]` is not sent to SIWC, because the preview does not list `include` among its supported fields; reasoning items are therefore not passed back between tool rounds (the model may reason a little more per round). Revisit when OpenAI documents it.
- Codex tool approval defaults to `writes` (Codex asks before every RecallSpring tool not marked read-only): it is the only mode Codex's docs define (2026-11-21); `auto`, `prompt` and `approve` are passed through unchanged when chosen. Study folders ask Codex for `sandbox_mode = "read-only"`, which Codex applies only after the learner trusts the folder; RecallSpring never marks folders as trusted.
- An app gets the inline form only when it announces MCP Apps support when it connects; otherwise the link fallback is used, even if the app could render forms in practice.
- Default daily plan 20 minutes, editable. Time zone chosen at first run (the browser's by default; server default UTC), editable in Settings → Profile.
- Source deletion soft-delete window 30 days proposed; subject to owner's final preference and legal/privacy policy.
- "Topic" in API/notes means a `syllabus_item`; "teacher correction" means the owner's own manual grade correction.
